## 문제의 내용 
[문제 링크](https://www.acmicpc.net/problem/13976)

$3 \times n$ 직사각형을 도미노($1 \times 2$이거나 $2 \times 1$)만을 사용하여 빈틈없이 덮는 경우의 수를 구하는 문제입니다. 
$2 \times n$ 타일 채우기 문제와 구성은 동일하나 행이 하나 추가되어 난이도가 살짝 올라갔습니다. 

## 문제해결 전략
생성함수에 대한 지식이 있으면 $2 \times n$에서의 아이디어와 약간의 계산을 통해 이차 선형동차점화식(linear homogeneous recurrence relation)을 얻을 수 있습니다. 
이를 위해 주어진 $n$에 대해 문제의 해를 $a_n$이라고 합시다. 
먼저 자명한 경우는 $n$이 홀수인 경우인데, 
이때 $3 \times n$는 홀수이므로 정사각형의 수가 짝수인 도미노로는 이 공간을 덮을 수 없으므로 $a_n = 0$입니다. 

다음으로 $n$이 짝수인 경우만을 고려할 것입니다. 
표기의 편의를 위하여 $b_n = a_{2n}$이라고 하고, $b_0 = 1$이라고 둡니다. 
(약간은 임의적으로 보이는 이 값은 이후에 나타나는 점화식을 자연수 전체에서 정의하기 위한 것이고 실제로 자연스러움이 간접적으로 나타납니다.)
먼저 $b_1 = 3$임은 문제의 예시 출력에서도 $3$임이 나타나고 실제로 세 가지 경우만이 존재합니다. 
이제 임의 자연수 $n$에 대해 $b_n$를 셀 때, 
가장 왼쪽에 있는 타일에 대해 $3 \times n$ 중 다시 부분적으로 $3 \times n^{\prime}$ 직사각형이 도미노에 의해 완전히 덮히게 되는 음이 아닌 정수 $n^{\prime} $이 최소라고 합시다. 
$n^{\prime} = 0$이고 $n > 2$일 때, 이러한 $3 \times n^{\prime}$의 경우의 수는 $2$가지 뿐임을 발견할 수 있습니다. 
단, $n^{\prime} = 2$이면 예외적으로 $3 \times 2$를 채우는 경우의 수는 $3$입니다. 

위 발견을 종합하면 $b_n$에 대한 점화식
$$
\begin{aligned}
  b_{n + 1} &= 2 + 3b_{n} + 2b_{n - 1} + \cdots + 2b_{2} \\\\
    &= b_n + 2 \sum_{i = 0}^{n}b_i
\end{aligned}
$$
을 얻을 수 있습니다. 

이제 $f(x)$를 $b_n$의 생성함수라고 합시다. 
생성함수의 정의에 따라서, 
$$
\begin{aligned}
  f(x) &= \sum_{n = 0}^{\infty} b_nx^n \\\\
  &= 1 + \sum_{n = 0}^{\infty} b_{n + 1}x^{n + 1} \\\\
  &= 1 + \sum_{n = 0}^{\infty} \left[ 2\sum_{k = 0}^{n}b_k + b_n \right]x^{n + 1} \\\\
  &= 1 + xf(x) + 2x\sum_{n = 0}^{\infty} \left[ \sum_{k = 0}^{n}b_k \right]x^n \\\\
  &= 1 + xf(x) + 2x \frac{f(x)}{1 - x} \\\\
\end{aligned}
$$
이고, 이 방정식을 $f(x)$에 대하여 풀면 
$$ f(x) = \frac{1 - x}{1 - 4x + x^2} $$
를 얻을 수 있습니다. 
여기서 선형동차방정식에 대한 한 정리에서 이 해와 같은 형태의 생성함수를 볼 수 있습니다: 
> 선형동차점화식
> $$ r_n = c_1r_{n - 1} + c_2r_{n - 2} + \cdots c_kr_{n - k} $$
> 을 만족하는 수열 $(r_n)$의 생성함수 $f(x)$는 차수가 $k$보다 작은 다항식 $g(x)$에 대해
> $$ f(x) = \frac{g(x)}{1 - r_1x - r_2x^2 - \cdots - r_kx^k} $$
> 이다. 

따라서 $b_n$의 선형동차점화식을 
$$ b_{n + 2} - 4b_{n + 1} + b_n = 0, b_0 = 1, b_1 = 3 $$
으로 유추할 수 있고 실제로 점화식이 맞습니다. 
마지막으로 큰 차수의 항을 구하기 위해 행렬의 거듭제곱을 통한 선형동차점화식의 계산 기술을 이용하면 문제를 해결할 수 있습니다. 

## 제출한 코드
```csharp
namespace Main;

class Program {
	const long MODULAR = 1_000_000_007;

	class Vector2 {
		public long X { get; set; }
		public long Y { get; set; }

		public Vector2(long x, long y) {
			(X, Y) = (x, y);
			X %= MODULAR;
			Y %= MODULAR;
		}
	}

	class SquareMatrix {
		public long X11 { get; set; }
		public long X12 { get; set; }
		public long X21 { get; set; }
		public long X22 { get; set; }
		public static SquareMatrix Identity = new(1, 0, 0, 1);

		public SquareMatrix(long x11, long x12, long x21, long x22) {
			(X11, X12, X21, X22) = (x11, x12, x21, x22);
			X11 %= MODULAR;
			X12 %= MODULAR;
			X21 %= MODULAR;
			X22 %= MODULAR;
		}

		public static SquareMatrix operator *(SquareMatrix m1, SquareMatrix m2) {
			return new SquareMatrix(
				m1.X11 * m2.X11 % MODULAR + m1.X12 * m2.X21 % MODULAR,
				m1.X11 * m2.X12 % MODULAR + m1.X12 * m2.X22 % MODULAR,
				m1.X21 * m2.X11 % MODULAR + m1.X22 * m2.X21 % MODULAR,
				m1.X21 * m2.X12 % MODULAR + m1.X22 * m2.X22 % MODULAR
			);
		}
		public SquareMatrix Pow(ulong n) {
			if (n == 0) return Identity;
			if (n == 1) return this;
			var half = Pow(n / 2);
			if (n % 2 == 0) return half * half;
			else return half * half * this;
		}
		public Vector2 TransformVector(Vector2 v) {
			return new Vector2(
				X11 * v.X % MODULAR + X12 * v.Y % MODULAR,
				X21 * v.X % MODULAR + X22 * v.Y % MODULAR
			);
		}
	}
	public static void Main(string[] args) {
		ulong inputN = ulong.Parse(Console.ReadLine()!);
		long result;
		if (inputN % 2 != 0) result = 0;
		else if (inputN == 0) result = 1;
		else if (inputN == 2) result = 3;
		else {
			SquareMatrix mat = new(4, MODULAR -  1, 1, 0);
			mat = mat.Pow(inputN / 2);
			result = mat.TransformVector(new(3, 1)).Y;
		}
		Console.WriteLine(result);
	}
}
```

## 특이사항
거듭제곱 하는 행렬은 $ \left(\begin{smallmatrix} 4 & -1 \\\\ 1 & 0 \end{smallmatrix}\right) $인데, 
각 성분을 양수로 유지하기 위하여 $-1$을 $1,000,000,006$으로 변환하였습니다.
